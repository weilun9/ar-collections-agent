L4 运行时策略层 · 硬规则

这些规则用 Python 实现，不读 prompt、不调模型。system prompt 里写的约束是软的 （可能被忽略、被注入绕过、在长上下文里遗忘），这一层是硬的：命中即执行，Agent 没有办法说服它。 每条规则只能让结果更严格，不能放宽 —— 这个单调性保证新增规则永远不会意外打开一个口子。

L2 预设模板 · Agent 的话语权边界

渲染函数的签名是 render(template_id, variables) —— 没有 body 参数。 Agent 能选模板、能填金额日期，但无法凭空生成一句「我们同意贵司分期」。 这不是「要求它别这么做」，是它做不到。
